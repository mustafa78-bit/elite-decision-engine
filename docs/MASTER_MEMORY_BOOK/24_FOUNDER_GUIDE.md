# Chapter 24: Founder Guide

## 🏛️ Founder Experience & Alpha Journey
NEXUS was created for **Founder Alpha**—meaning the founder uses the platform daily to make actual trading decisions. This ensures that the platform is guided by real-world usage and practical feedback, rather than abstract feature requirements.

---

To get the most out of the platform, the Founder should follow this structured daily workflow:

```
+---------------------------------------------------------------------------------+
|                                 1. THE MORNING BRIEF                            |

|  - Review OLLO's natural-language morning briefing.                             |
|  - Review risk metrics (Sharpe ratio, current drawdown limits).                 |
+---------------------------------------------------------------------------------+
                                         |
                                         v
+---------------------------------------------------------------------------------+
|                                2. COGNITIVE AUDIT                               |
|  - Review newly ingested signals on the Watchlist.                              |

+---------------------------------------------------------------------------------+
                                         |
                                         v
+---------------------------------------------------------------------------------+
|                                3. EXECUTION GATEWAY                             |
|  - Manually validate and approve highly-rated recommendations.                  |

                                         |
                                         v
+---------------------------------------------------------------------------------+

|  - Build a permanent history of decisions to improve future AI Council context. |
+---------------------------------------------------------------------------------+
```

## 🏛️ Founder Operating Principles

Every feature and interface in NEXUS is designed to uphold these core operational principles:

### 1. Simple, Clean Dashboards
Keep dashboards focused and free of clutter. Grid cards and HUD metrics should be optimized to reduce cognitive load, presenting key risk and performance metrics clearly without burying them in raw math equations.

### 2. Never Bypass Human Sovereignty
The platform acts as a cognitive extension of the human trader. While background execution loops handle data collection, pre-flight safety checks, and simulation tracking, **the human operator always makes the final trading decision**.

### 3. Continuous Qualitative Feedback
Quantitative data (such as returns and drawdowns) is only half the story. Enforcing qualitative journaling (e.g., tracking emotional discipline and decision notes) helps identify psychological patterns, leading to more disciplined execution over time.
