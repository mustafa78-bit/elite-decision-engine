# Chapter 18: Command Center

## 🖥️ Executive Control Hub
The **NEXUS Command Center** (`frontend/src/pages/CommandDeck.tsx`) serves as the primary visual interface for the sovereign trader. Designed as a high-density, 12-column grid layout, it aggregates multiple real-time widgets onto a single screen, minimizing cognitive load and providing a complete operational snapshot at a glance.

### Core HUD Widgets (Mounted in `CommandDeck.tsx`):
1. **`FounderMorningBrief.tsx`**: Provides an executive natural-language briefing generated by OLLO, summarizing key market developments and overnight delta shifts.
2. **`PortfolioSummaryWidget.tsx`**: Displays key risk-adjusted metrics, including Sharpe/Sortino ratios, open margin limits, and daily balance fluctuations.
3. **`AICouncilWidget.tsx`**: Displays real-time agent positions, consensus direction ratings, and logs from active council debates.
4. **`RiskAlerts.tsx`**: Displays warnings for critical system states, such as extreme asset volatility or drawdown threshold violations.
5. **`WatchlistWidget.tsx`**: Provides an interactive watchlist card with real-time price feeds, volume profiles, and trend classifications.
6. **`AIDecisionTimeline.tsx`**: Shows a vertical stepping feed mapping active signals, debate sequences, and execution outcomes.

## ⚡ Real-Time WebSockets Integration
The Command Center features deep real-time integration via WebSockets. When a browser client mounts the page, it automatically establishes authenticated multiplex connections to several WebSocket channels (`"trades"`, `"dashboard"`, `"notifications"`).

As market movements or background loops update prices, regimes, or risk scores, delta updates are instantly pushed to the browser. This updates metrics, dials, and alerts in real time with high visual fluidness, avoiding the overhead of polling.
